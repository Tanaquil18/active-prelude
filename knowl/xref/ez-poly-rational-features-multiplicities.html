Exercise 9.

For each of the following rational functions, identify the location of any potential hole in the graph. Then, create a table of function values for input values near where the hole should be located. Use your work to decide whether or not the graph indeed has a hole, with written justification.
🔗
  1. \(\displaystyle \displaystyle r(x) = \frac{x^2-16}{x+4}\)
    🔗
    🔗
  2. \(\displaystyle \displaystyle s(x) = \frac{(x-2)^2(x+3)}{x^2 - 5x - 6}\)
    🔗
    🔗
  3. \(\displaystyle \displaystyle u(x) = \frac{(x-2)^3(x+3)}{(x^2 - 5x - 6)(x-7)}\)
    🔗
    🔗
  4. \(\displaystyle \displaystyle w(x) = \frac{x^2 + x - 6}{(x^2 + 5x + 6)(x+3)}\)
    🔗
    🔗
  5. True or false: given \(r(x) = \frac{p(x)}{q(x)}\text{,}\) if \(p(a) = 0\) and \(q(a) = 0\text{,}\) then \(r\) has a hole at \(x = a\text{.}\)
    🔗
    🔗
🔗
Solution.
  1. \(r(x) = \dfrac{x^2-16}{x+4} = \dfrac{(x-4)(x+4)}{x+4}\text{.}\) At \(x = -4\text{,}\) both numerator and denominator are zero. After cancellation, \(r(x) = x-4\) for \(x \neq -4\text{.}\) Near \(x = -4\text{,}\) the values approach \(-4-4 = -8\) (e.g., \(r(-3.9) \approx -7.9\)). So the graph has a hole at \((-4, -8)\text{.}\)
    🔗
    🔗
  2. \(s(x) = \dfrac{(x-2)^2(x+3)}{x^2-5x-6} = \dfrac{(x-2)^2(x+3)}{(x-6)(x+1)}\text{.}\) The denominator zeros are \(x = 6\) and \(x = -1\text{;}\) neither equals a numerator zero. There are no holes.
    🔗
    🔗
  3. \(u(x) = \dfrac{(x-2)^3(x+3)}{(x^2-5x-6)(x-7)} = \dfrac{(x-2)^3(x+3)}{(x-6)(x+1)(x-7)}\text{.}\) The denominator zeros \(x=6\text{,}\) \(x=-1\text{,}\) \(x=7\) share no factors with the numerator. There are no holes.
    🔗
    🔗
  4. \(w(x) = \dfrac{x^2+x-6}{(x^2+5x+6)(x+3)} = \dfrac{(x+3)(x-2)}{(x+2)(x+3)^2}\text{.}\) One factor of \((x+3)\) cancels, leaving \(\dfrac{x-2}{(x+2)(x+3)}\text{.}\) At \(x=-3\text{,}\) the original is \(0/0\) and the reduced form still has \((x+3)\) in the denominator, so \(x=-3\) is a vertical asymptote, not a hole. There are no holes.
    🔗
    🔗
  5. False. Part (d) provides a counterexample: at \(x=-3\text{,}\) both \(p(-3)=0\) and \(q(-3)=0\text{,}\) yet the graph has a vertical asymptote rather than a hole. A hole occurs only when the factor cancels completely in the reduced form.
    🔗
    🔗
