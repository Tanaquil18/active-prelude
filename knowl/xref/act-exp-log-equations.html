Activity 3.4.4.

Solve each of the following equations for the exact value of the unknown variable. If there is no solution to the equation, explain why not.
🔗
🔗

(a)

\(e^t = \frac{1}{10}\)
🔗
Solution.
\(t = \ln\!\left(\frac{1}{10}\right) \approx -2.30\)
🔗
🔗
🔗

(b)

\(5e^{t}=7\)
🔗
Solution.
\(t = \ln\!\left(\frac{7}{5}\right) \approx 0.336\)
🔗
🔗
🔗

(c)

\(\ln(t) = -\frac{1}{3}\)
🔗
Solution.
\(t = e^{-1/3} \approx 0.717\)
🔗
🔗
🔗

(d)

\(e^{1-3t} = 4\)
🔗
Solution.
\(e^{1-3t} = 4\) gives \(1 - 3t = \ln 4\text{,}\) so \(t = \dfrac{1 - \ln 4}{3} \approx -0.129\text{.}\)
🔗
🔗
🔗

(e)

\(2\ln(t) + 1 = 4\)
🔗
Solution.
\(2\ln(t) + 1 = 4\) gives \(\ln(t) = \frac{3}{2}\text{,}\) so \(t = e^{3/2} \approx 4.48\text{.}\)
🔗
🔗
🔗

(f)

\(4 - 3e^{2t} = 2\)
🔗
Solution.
\(4 - 3e^{2t} = 2\) gives \(e^{2t} = \frac{2}{3}\text{,}\) so \(t = \frac{1}{2}\ln\!\left(\frac{2}{3}\right) \approx -0.203\text{.}\)
🔗
🔗
🔗

(g)

\(4 + 3e^{2t} = 2\)
🔗
Solution.
There is no solution because the equation gives \(e^{2t} = -\frac{2}{3}\text{,}\) and there is no exponent for which \(e\) raised to that power is negative.
🔗
🔗
🔗

(h)

\(\ln(5 - 6t) = -2\)
🔗
Solution.
\(\ln(5 - 6t) = -2\) gives \(5 - 6t = e^{-2}\text{,}\) so \(t = \frac{5 - e^{-2}}{6} \approx 0.811\text{.}\)
🔗
